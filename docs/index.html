About the Project

A Python-based unit converter developed by a three-member team to practice GitHub collaboration, unit testing, code reviews, and CI/CD.

Features

  • Temperature: Celsius and Fahrenheit
  • Length: Metres, kilometres, and miles
  • Weight: Kilograms, grams, and pounds

Our Team

  • AMR KABELMA - Temperature conversions
  • SARA BENSLIMANE - Length conversions and CI
  • MIRA NEGRA - Weight conversions and GitHub Pages

Running the Tests

Clone the repository and install dependencies:

pip install -r requirements.txt
python -m pytest -q

Automated tests run using GitHub Actions when changes are pushed or a Pull Request is opened.
